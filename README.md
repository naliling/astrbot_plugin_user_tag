# 关系识别插件 —— 让 AI 记住你与它的独特关系

> 不只是标签，更是一段独一无二的相处方式，且小到不影响回复。

## 它是什么？

你希望 AI 怎么称呼你？是恋人、死对头，还是投喂员？  
这个插件让你用一个指令，就能彻底改变 AI 对你的语气和态度，并且让它记住。

- 预设 **48 种** 关系，涵盖亲密、友情、身份、趣味、家人，以及 **极端恋爱** 和 **强冲突/奇幻/权力向** 关系。
- 支持完全自定义。
- 自动注入上下文，AI 会自然而然按你设定的关系来回应。
- 管理员可代设、查看全群关系统计。

## 快速上手

| 你想做什么 | 输入指令 |
|------------|----------|
| 自己设定关系 | `设置关系 恋人` |
| 管理员代设（群内@） | `设置关系 @用户 傲娇` |
| 管理员代设（指定QQ） | `设置关系 123456789 天降` |
| 查看当前关系 | `查看我的关系` |
| 清理关系 | `清除关系` |
| 查看所有预设 | `关系列表` |
| 管理员查看全貌 | `查看所有关系` |
| 管理员关系统计 | `关系统计` |

## 管理员专属

- `查看所有关系` —— 列出所有用户的关系设置
- `关系统计` —— 统计各种关系的人数
- `设置关系 @用户 关系名` 或 `设置关系 QQ号 关系名` —— 代设或强制覆盖

## 配置项详解

| 配置 | 说明 |
|------|------|
| `admin_qq` | 管理员 QQ 列表（数组） |
| `default_relation` | 用户未设置关系时的默认称呼 |
| `enable_default_relation` | 是否启用默认关系 |

## 数据安全

- 数据保存在 `data/plugin_data/astrbot_plugin_user_tag/user_tag.json`
- 数据损坏时自动备份
- 所有读写操作均加锁

## 安装

放入 `plugins/` 目录，重启 AstrBot 即可。

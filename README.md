# 关系识别插件 —— 让 AI 记住你与它的独特关系

> 不只是标签，更是一段独一无二的相处方式，且小到不影响回复。

## 它是什么？

你希望 AI 怎么称呼你？是恋人、死对头，还是投喂员？  
这个插件让你用一个指令，就能彻底改变 AI 对你的语气和态度，并且让它记住。

- 预设 **32 种** 关系，涵盖亲密、友情、身份、趣味、家人，以及 **16 种极端恋爱/Galgame向** 关系（病娇、傲娇、天降、修罗场……）。
- 支持完全自定义，比如“游戏搭子”、“绘画导师”、“吐槽大师”……随便起。
- 自动注入上下文，AI 会自然而然按你设定的关系来回应。
- **新增管理员代设与强制覆盖**：管理员可以为任何用户设置或覆盖关系，适合群组管理或活动。
- **新增关系统计看板**：管理员可查看所有用户的关系分布，直观了解社群氛围。
- 灵活控制默认关系：可通过配置开关 `enable_default_relation` 决定是否对未设置关系的用户使用默认称呼。

## 快速上手

| 你想做什么 | 输入指令 |
|------------|----------|
| 自己设定关系 | `设置关系 恋人` |
| 管理员代设（群内@） | `设置关系 @用户 傲娇` |
| 管理员代设（指定QQ） | `设置关系 123456789 天降` |
| 查看当前关系 | `查看我的关系` |
| 清理关系 | `清除关系` |
| 查看所有预设 | `关系列表` |
| 管理员查看全貌 | `查看所有关系` |
| 管理员关系统计 | `关系统计` |

## 预设关系一览（32 种）

### 原有16种（经典）
恋人、暗恋者、前任、灵魂伴侣、闺蜜、挚友、青梅竹马、吐槽对象、树洞、主人、学徒、忠诚骑士、搭档、猫主子、投喂员、家人

### 新增16种（极端恋爱/Galgame向）
**病娇**、**傲娇**、**倒贴**、**纯情**、**溺爱**、**痴女/痴男**、**妹系**、**姐系**、**天降**、**共犯**、**修罗场**、**白月光**、**黑化**、**小恶魔**、**忠犬**、**追妻火葬场**

> 如果你想要的关系没在上面，随便输一个名字就行，AI 会按你给的称呼来调整语气。

## 管理员专属

- `查看所有关系` —— 列出所有用户的关系设置
- `关系统计` —— 统计各种关系的人数，按降序排列
- `设置关系 @用户 关系名` 或 `设置关系 QQ号 关系名` —— 代设或强制覆盖

## 配置项详解

| 配置 | 说明 |
|------|------|
| `admin_qq` | 管理员 QQ 列表（数组） |
| `default_relation` | 用户未设置关系且 `enable_default_relation` 为 `true` 时的默认称呼（默认“好友”） |
| `enable_default_relation` | 是否启用默认关系。关闭后，未设置关系的用户将不会收到任何关系注入。 |

## 数据安全

- 关系数据保存在 `data/plugin_data/astrbot_plugin_user_tag/user_tag.json`
- 数据损坏时自动备份为 `user_tag.json.bak` 并重建，防止丢失。
- 所有读写操作均加锁，保证并发安全。

## 安装

放入 `plugins/` 目录，重启 AstrBot 即可。

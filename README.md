# 关系识别插件 —— 让 AI 记住你与它的独特关系

> 不只是标签，更是一段独一无二的相处方式，且小到不影响回复。

## 它是什么？

你希望 AI 怎么称呼你？是恋人、死对头，还是投喂员？  
这个插件让你用一个指令，就能彻底改变 AI 对你的语气和态度，并且让它记住。

- 预设 16 种关系，涵盖亲密、友情、身份、趣味、家人五大类。
- 支持完全自定义，比如“游戏搭子”、“绘画导师”、“吐槽大师”……随便起。
- 自动注入上下文，AI 会自然而然按你设定的关系来回应。

## 快速上手

| 你想做什么 | 输入指令 |
|------------|----------|
| 设定关系 | `设置关系 恋人` |
| 查看当前关系 | `查看我的关系` |
| 清理关系 | `清除关系` |
| 查看所有预设 | `关系列表` |
| 管理员看全貌 | `查看所有关系` |

## 预设关系一览（16 种）

| 类别 | 包含关系 |
|------|----------|
| 亲密类 | 恋人、暗恋者、前任、灵魂伴侣 |
| 友情类 | 闺蜜、挚友、青梅竹马、吐槽对象、树洞 |
| 身份类 | 主人、学徒、忠诚骑士、搭档 |
| 趣味类 | 猫主子、投喂员 |
| 家人 | 家人 |

> 如果你想要的关系没在上面，随便输一个名字就行，AI 会按你给的称呼来调整语气。

## 管理员专属

发送 `查看所有关系`，可以看到所有用户设定的关系图谱，还能统计出哪种关系最受欢迎。

## 数据安全

关系数据保存在 `data/plugin_data/astrbot_plugin_user_tag/user_tag.json`，你可以随时备份或迁移。

## 配置项

| 配置 | 说明 |
|------|------|
| `admin_qq` | 管理员 QQ 列表 |
| `default_relation` | 用户未设置时的默认关系（默认“陌生人”） |

## 安装

放入 `plugins/` 目录，重启 AstrBot 即可。
